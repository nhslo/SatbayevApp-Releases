<h2 align="center">Download</h2>

<p align="center">
  Get the app from the <a href="https://github.com/nhslo/SatbayevApp-Releases/releases/latest">latest stable release</a>.
</p>

For most modern Android phones, download [app-arm64-v8a-release.apk](https://github.com/nhslo/SatbayevApp-Releases/releases/latest/download/app-arm64-v8a-release.apk). If you are unsure which architecture your phone uses, download [app-release.apk](https://github.com/nhslo/SatbayevApp-Releases/releases/latest/download/app-release.apk), the universal APK for supported devices. The release also contains architecture-specific packages for devices or deployment tools that require them:

| File | Intended device |
| --- | --- |
| `app-release.apk` | Universal APK; recommended if you are unsure |
| `app-arm64-v8a-release.apk` | Most modern Android phones |
| `app-armeabi-v7a-release.apk` | 32-bit ARM devices |
| `app-x86_64-release.apk` | x86_64 emulators and compatible devices |
