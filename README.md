# Satbayev App Releases

Official Android APK releases for Satbayev App.

The application source is maintained in a separate private repository. This public repository contains only signed release APK files and user-facing release notes so installed Android applications can check and download updates without embedding a GitHub token.

## Install

Open the latest release, download `app-release.apk`, and confirm installation in Android's system package installer. Future versions can also be installed from the in-app update prompt.

Android upgrades preserve application data when the APK uses the same application ID and signing certificate and has a higher version code.
